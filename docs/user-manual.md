# User Manual

This manual describes the planned MVP workflow.

## Getting started

1. Create an account with a unique username, or sign in using either your username or email address.
2. Create or select the active semester.
3. Add teachers and subjects.
4. Enter each subject's credit hours, attendance threshold, and weekly schedule.

## Mark attendance

1. Open the Dashboard.
2. Find the class in Today's classes.
3. Select Present, Absent, Late, or Excused.
4. Confirm the saved result and review the updated percentage.

To correct a result, open the subject's attendance history, select the class occurrence, and edit or remove the record.

## Read the attendance summary

Each subject shows attended sessions, total counted sessions, absences, percentage, and threshold status. A percentage below the threshold is marked as at risk. Excused sessions appear separately.

## Add an assignment

1. Open Assignments and select Add assignment.
2. Choose the subject.
3. Enter a title, due date, and optional notes.
4. Save the assignment and mark it complete when finished.

## Add a makeup class

1. Open the relevant subject or schedule.
2. Select Add makeup class.
3. Enter the date, time, teacher, and optional note.
4. Save it, then mark attendance when the class takes place.

## Account and privacy

Sign out after using a shared device. Attendance, assignment, and schedule data belongs to the signed-in account and should not be shared through public links.
