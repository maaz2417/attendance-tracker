# Product Roadmap

## Phase 1: Foundation

- Select hosting, authentication, database, and frontend stack.
- Implement the schema and authorization model.
- Establish attendance calculation tests and API conventions.

## Phase 2: MVP

- Account sign-in and protected data.
- Semester, subject, teacher, and schedule management.
- Today's classes dashboard.
- Present, absent, late, and excused attendance.
- Subject and overall summaries with 75% warnings.
- Assignment and makeup-class management.
- Responsive mobile-first interface.

## Phase 3: Quality and convenience

- Attendance history filters.
- Calendar view.
- CSV/PDF reports.
- Notifications for low attendance and due assignments.
- Improved empty states and lightweight celebratory feedback.

## Phase 4: Expansion

- Flutter client using the same API.
- Offline mode with conflict-safe synchronization.
- QR check-in.
- Role-based teacher and administrator accounts.
- Spreadsheet import and multi-student management.

Features should move phases only after the previous phase has reliable data integrity and test coverage.
