## Product definition

The MVP is a mobile-first web application for one authenticated university student to manage Semester 5 subjects, schedules, attendance, assignments, and makeup classes. Data is stored online so the application can later support a Flutter client without changing the core data or business rules.

## Status

The repository currently contains a static HTML/CSS prototype. These documents describe the target MVP and provide the implementation contract for the next development phase.
